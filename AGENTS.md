# Agent Instructions

- Keep the Roller Coaster Designer implementation consistent with `spec.md`.
- Use plain HTML, CSS, and JavaScript unless the project specification requires a framework.
- Keep the interface accessible: labeled controls, visible focus states, semantic elements, and keyboard support.
- Do not add features outside the scope in `spec.md`.
- Before making changes, read `spec.md` and check existing project files.
- After every completed request, append a dated entry to `prompts.md` containing:
  1. What was asked.
  2. What was changed.
  3. Whether it worked.
